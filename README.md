## Troubleshooting approach

1. Clarify the symptoms and business/user impact.
2. Establish the scope: one user, several users, one device or a wider service.
3. Gather relevant evidence before changing settings.
4. Test likely causes methodically and safely.
5. Apply an appropriate fix only within the scenario's permissions and procedures.
6. Verify the outcome; if it cannot be verified, say so.
7. Document findings, actions, outcome and any escalation or follow-up needed.
