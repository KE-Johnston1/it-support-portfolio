# Case Study: Calendar Synchronisation

**Category:** Application support  
**Environment:** Simulated service desk  
**Skills illustrated:** Reproducing symptoms, controlled troubleshooting and verification

> This is a simulated learning exercise.

## 1. Scenario

A user reports that their calendar is not synchronising correctly in the mail client.

## 2. Investigation approach

Before making changes, clarify whether the problem affects one calendar, one device or multiple clients. Check for service alerts or wider reports if those checks are available in the environment. Record the exact symptom and any error messages.

## 3. Simulated procedure

The original exercise describes using the remote desktop, opening Control Panel, locating the mail client in Programs and Features and selecting its repair option.

The repair action should be used only if it is available and appropriate in the environment. In a real workplace, follow the organisation's approved support procedure and consider whether repair could affect local configuration.

## 4. Verification

After the repair completes, reopen the mail client and check whether the calendar synchronises. If the problem remains, record the result and investigate further or escalate rather than closing the ticket.

## 5. Learning points

- Gather enough detail to scope an application issue.
- Follow approved procedures before repairing software.
- Confirm the original symptom has cleared.
- Document the outcome, including any unsuccessful checks.
